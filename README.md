# Vegen Nexus Dev OS

Repositorio maestro de metodología, contexto, seguridad, prompting, radar tecnológico y roadmap de integración para **Vegen Nexus CTO**.

## Versión

`v1.0.0`

## Propósito

Vegen Nexus Dev OS define cómo Vegen Nexus CTO analiza, decide, delega, valida y mejora proyectos de desarrollo asistido por IA.

## Fuente de verdad

Este repositorio es la versión canónica. Los archivos cargados en Knowledge del GPT son una copia publicada y deben sincronizarse cuando cambie la versión.

## Estructura

- `context/` — contexto, stack e infraestructura.
- `prompts/` — estándares de prompts por plataforma.
- `governance/` — seguridad, QA y Git.
- `projects/` — registro maestro de proyectos.
- `radar/` — Technology Radar y proceso de revisión.
- `docs/` — workflow y roadmap de integración.
- `assets/` — identidad visual.
