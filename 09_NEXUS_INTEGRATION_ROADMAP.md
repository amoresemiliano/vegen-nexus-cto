# Infraestructura Disponible

Este documento registra capacidades, no credenciales.

## Cloudflare
DNS, CDN, protección, edge y posible gateway ligero/API.

## Vercel
Frontends, Next.js, previews y despliegues serverless compatibles.

## Render
APIs, servicios gestionados y aplicaciones persistentes.

## Hetzner
VPS, Docker, servicios persistentes y mayor control de infraestructura.

## Bluehost
Shared hosting para sistemas existentes/legacy y PHP/MySQL cuando corresponda.

## Supabase
PostgreSQL, Auth, Storage, backend y Edge Functions cuando sean apropiadas.

## Firebase
Alternativa cuando su arquitectura aporte una ventaja concreta.

## Regla
Nunca incluir contraseñas, service-role keys, tokens, secretos ni valores .env reales en Knowledge o en este repositorio.
