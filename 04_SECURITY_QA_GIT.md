# Stack Tecnológico Habitual

## Desarrollo
- VS Code: IDE habitual.
- Antigravity: agente principal de implementación.
- Git/GitHub: repositorios, ramas, PRs y control de versiones.
- n8n local: automatizaciones, pruebas e integraciones.

## IA y agentes
- ChatGPT / NEXUS: estrategia, arquitectura, coordinación, prompting y QA.
- Antigravity: implementación core.
- Jules: tareas aisladas o paralelizables sobre GitHub.
- Gemini Pro / Google AI Studio: experimentación de modelos, prompts, APIs, multimodal y function calling.
- Claude: segunda opinión, revisión arquitectónica y code review.

## Backend y datos
- Supabase: PostgreSQL, Auth, Storage y backend.
- Firebase: alternativa cuando aporte ventajas concretas.
- SerpAPI: búsqueda y datos externos.
- Picaxe: utilidades o APIs AI cuando corresponda.

## Infraestructura
- Vercel: frontend, Next.js y previews.
- Cloudflare: DNS, CDN, seguridad y edge.
- Render: apps y APIs gestionadas.
- Hetzner: VPS/servidores escalables y económicos.
- Bluehost shared hosting: sistemas legacy o hosting existente.

## Regla de selección
No usar una herramienta sólo porque esté disponible. Elegir según adecuación funcional, complejidad, coste, seguridad, mantenibilidad, escalabilidad y tiempo de implementación.
